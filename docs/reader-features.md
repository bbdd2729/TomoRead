# TomoRead 阅读能力与数据边界

## 已支持的阅读能力

| 能力 | EPUB | PDF | TXT / Markdown |
| --- | --- | --- | --- |
| 导入、托管与哈希去重 | 支持 | 支持 | 支持 |
| 章节、目录与搜索 | 支持 | 支持 | 支持章节识别与搜索 |
| 阅读位置与书签 | 支持 | 支持 | 支持 |
| 标注与全局笔记 | 支持划线、高亮和笔记 | 仅书签/阅读位置 | 通过全局笔记关联 |
| 排版与字体 | 支持 | 阅读器控制 | 支持 |
| 简繁、全半角、文本替换 | 不适用 | 不适用 | 支持显示投影 |
| 文本前景色 | 支持 | 未支持 | 未支持 |
| 阅读助手与可视化 | 支持 | 受可靠文本范围限制 | 支持 |

系统字体和导入字体均可用于阅读设置。番茄专注、阅读活动统计、本地词云和 AI 思维导图已可用；可视化结果是派生数据，可导出 JSON、SVG 或 PNG。

## 定位与原文完整性

TomoRead 不修改导入的 EPUB、PDF、TXT 或 Markdown 原文。编码转换、简繁转换、文本替换、搜索索引和可视化都属于派生数据。

- EPUB 使用 `href` 与 CFI、锚点或比例等定位数据。
- PDF 定位以页码为基础；只有在存在可靠文本范围时才允许建立文本引用或 AI 上下文。
- TXT / Markdown 的显示转换必须保持 raw/display 映射。映射不精确的范围不能用于标注、复制、定位或着色。

任何新增的渲染效果都不能破坏阅读位置、搜索结果、选区、标注或主题切换。阅读器与嵌入式 runtime 的消息必须有明确 schema，并对白名单字段做校验。

## 标注、笔记与导出

标注由原文定位、选中文字、颜色、备注、标签和时间构成。全局笔记对这些记录进行汇总，并能回跳到原文。当前导出格式为 Markdown 和 JSON，导出内容不会包含密钥或其他凭据。

为避免定位漂移，后续功能不得将 EPUB CFI 强行用于 PDF 或纯文本；应按文档格式设计专用 locator，并在内容变化或无法确认时向用户说明风险。

## 阅读助手与内容安全

阅读助手仅从可信 `content_chunks` 中取回上下文，支持关键词检索、引用回跳和防剧透范围控制。AI 工具调用与其结构化结果会随会话持久化。词云和思维导图使用同一可信内容来源，不能凭空构造原文位置。

## 后续演进原则

下列能力仍在规划中：PDF 文本选区标注、TXT/Markdown 正文着色、系统 TTS、EPUB 脚注与图片查看、自动滚动，以及语义检索。它们必须保持本地优先、可回跳、可降级和不泄露原文/凭据这四项原则。
