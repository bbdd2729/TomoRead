# TomoRead 产品路线图

TomoRead 的目标是成为本地优先、可回跳且具备知识整理能力的跨平台阅读器。ColorTxt 与 ReadAny 用作产品行为和架构参考；不会复制其源码、资源、私有协议或文案。

## 当前基线

目前已具备 EPUB、PDF、TXT 和 Markdown 导入；EPUB 标注、书签与全局笔记；系统/导入字体；TXT/Markdown 显示投影；番茄专注；可信内容检索与阅读助手；词云、思维导图；以及多 Provider 的 AI 对话配置。

## 优先级

| 优先级 | 主题 | 交付结果 |
| --- | --- | --- |
| P0 | 定位契约与回归样本 | 不同格式在重启、搜索、布局变化后仍可验证地回到原文 |
| P0 | 版本化备份、恢复与存储诊断 | 校验后的本地备份、可回滚恢复和安全缓存清理 |
| P0 | 同步数据模型 | 实体版本、删除墓碑和确定的冲突处理，为远程同步建立基础 |
| P1 | WebDAV 手动同步 | 显式触发、可观察、可中断和可恢复的同步 |
| P1 | 系统 TTS | 以阅读 locator 驱动的朗读游标和跨平台降级 |
| P1 | EPUB 交互完善 | 脚注、图片查看以及安全的内外部链接策略 |
| P1 | PDF 文本标注 | 基于页码和矩形选区的标注、导出与 AI 引用 |
| P1 | TXT/Markdown 正文着色 | 在可靠 raw/display 映射上复用现有词条规则 |
| P1 | 文件接入与效率 | 桌面拖放、目录导入、文件关联、移动端分享导入、快捷键和自动滚动 |
| P1 | 语义检索 | 可选 embedding 与关键词检索的混合排序，始终保留无模型降级路径 |

## 依赖顺序

先完成定位契约，再交付备份与同步数据模型；WebDAV 依赖全部 P0。EPUB、PDF、文件接入和阅读效率功能可以在定位基础稳定后并行推进。TTS 使用已解析的 EPUB/TXT/Markdown 内容；PDF 只有在可靠文本定位完成后才接入。语义检索不应成为普通全文搜索的前置条件。

## 不纳入当前路线图

额外电子书格式（MOBI、AZW、FB2、CBZ 等）、在线书源、自动更新、云端多音色 TTS、正文副本编辑及 macOS/iOS 支持不属于当前 P0/P1。在线书源必须先完成版权、地区合规、反爬与凭据隔离评审。

## 交付与验证

每个功能应拆成范围清晰的提交，包含必要的迁移、测试和文档更新。当前开发机可不安装 Flutter；推送后由 GitHub Actions 的 `Verify` 作最终验证，执行 `flutter pub get`、`flutter analyze lib test` 和 `flutter test`。平台构建任务不作为单个功能提交的默认等待条件。
